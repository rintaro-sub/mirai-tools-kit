# Mirai Tools Portal

学生チーム【運営】向けの静的プロトタイプ。ミント・太枠・丸ゴシックの既存デザインを継承しています。HTML / CSS / JavaScriptのみで動作し、依存追加・外部通信はありません。

## 起動・確認

リポジトリのルートで実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

- ローカル版：<http://localhost:8000/static/index.html>
- Pages相当：<http://localhost:8000/docs/index.html>
- GitHub Pagesは公開元を `docs/` に設定してください。
- ngrokで別途公開する場合は、`python3 -m http.server 8000 --directory static --bind 127.0.0.1` と `ngrok http 8000` を使用できます。

`static/` と `docs/` は同じ公開ファイルです。リンク・アセット参照はすべて相対パスです。作業用資料や設定ファイルは公開ディレクトリへ入れません。

## 操作の確認手順

1. indexから各部門へ移動し、左ナビとポータルへの戻りを確認。
2. 企画を追加→編集→再読み込みして保存を確認→削除。検索に一致しない語を入力して空状態も確認。
3. 各部門のタブを切り替えてローディングを確認。広報で下書き→承認待ち→承認済み→下書きに戻す操作を確認。
4. 議事録の編集・保存、役員会のタスク化、タスク完了後に再読み込みして保持を確認。
5. 文書検索、FAQ展開、通知文保存、トースト、Escapeでのモーダル終了、Tabキーでの操作を確認。
6. 幅390px程度で確認。企画表は表の領域内を横スクロールできます。
7. docs側でも同じ操作を実施。`diff -qr static docs` で配布ファイルの一致を確認。

データは `mirai.portal.` で始まるlocalStorageキーに保存します。ブラウザ・オリジンごとに独立し、端末間で同期しません。同じオリジンのstatic/docsでは共用します。ブラウザのサイトデータを消すとサンプルへ戻ります。保存が禁止されている場合はエラーを表示します。

日程・担当者・文書・承認状態は架空のサンプルです。通知・承認・外部公開は画面内だけの動作です。秘密情報・個人情報・実際の面談記録は入力しないでください。
