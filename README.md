# 政策立案部門・週次レポートダッシュボード

学生チーム【運営】の部門長が、今週の実績と来週の準備をまとめて確認する静的デモです。HTML / CSS / JavaScriptをすべて `index.html` に収め、外部ライブラリ・CDN・外部通信を使いません。

## 起動

`static/index.html` をブラウザで開きます。ローカルサーバーを使う場合は次のコマンドを実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

`http://localhost:8000/static/index.html` にアクセスしてください。GitHub Pages向けの `docs/index.html` は同一ファイルです。配布にはどちらかの `index.html` だけで足ります。既存のその他のHTML・JS・CSSはダッシュボードから参照しません。

## 使い方

- 「前週」「次週」で月曜〜日曜の表示週を移動します。サマリーの4指標には先週比を表示します。
- メンバー負荷にマウスを重ねるか、Tabキーでフォーカスすると、タスク名・状態・期限が表示されます。Escapeでフォーカスを外せます。タスク0件は「未割り当て」です。
- 来週のMTGの状態バッジをクリック、またはEnter / Spaceキーで押すと、未準備の項目が開きます。もう一度押すと閉じます。
- PJカードの「詳細」で未完了タスク、工程目標日、期限超過数を確認できます。キーボードでも操作できます。
- 「週次サマリーをコピー」で表示週のMarkdownをクリップボードへコピーし、定例の議事録に貼り付けます。コピーAPIを使えない場合は、手動コピー用ダイアログが開きます。全文選択後にCtrl+C / Cmd+Cでコピーしてください。Escapeまたは「閉じる」で戻れます。

PCは最大幅1120px、スマートフォン390pxでは各セクションが縦に並びます。詳細を開くと画面の高さは伸びます。フォントは端末内の日本語フォントを使用し、配信しません。

## データ・集計ルール

初回に開いた週を基準として、架空のメンバー8名、進行中PJ5件、タスク30件、前週・今週・来週それぞれ4件のMTGを生成し、`localStorage` の `mirai.dashboard.v1` に保存します。今週のMTGは月・水・金・土です。保存データはリロード後も維持され、週移動で再生成しません。実システム（policy-planning-tool-oss / Workers / D1）との連携はありません。

- MTG数は予定日、議事録は作成日、完了タスクは完了日、新規タスクは作成日で集計します。MTG数には未開催の予定も含みます。
- 負荷は「表示週に期限があるタスク」「それ以前が期限の未完了タスク」「表示週の直後1週間に期限が来る未完了タスク」の合計です。今週は今日、その他の週は日曜を判定日とします。期限当日は期限超過扱いにしません。
- 準備完了：議題設定・資料確認が済み、前回宿題0件。要対応：3項目すべてが未完了。それ以外の未完了は要注意です。
- PJ健康度は、期限超過2件以上、または工程目標日超過かつ進捗100%未満で「要フォロー」。期限超過1件、または工程目標まで14日以内で進捗70%未満は「やや遅れ」。それ以外は「順調」です。
- タスク完了率は判定日までの完了日で算出します。工程名・工程進捗は保存された最新値であり、過去の工程履歴を再現するものではありません。

データの編集UIはありません。初期化する場合はブラウザの開発者ツールでこのキーだけを削除し、再読み込みしてください。旧ツールの別キーは変更しません。保存不可・不正データの場合は通知を表示し、一時サンプルで動作します。不正データは自動で上書きしません。

## 検証

インラインJavaScriptの構文チェックと、jsdomによる主要導線のDOMテストを実施済みです。開発時のテストにはNode.jsとjsdomが必要ですが、配布HTMLには不要です。

```sh
python3 - <<'PY'
from pathlib import Path
import re
s = Path('static/index.html').read_text()
Path('/tmp/dashboard-script.js').write_text(re.search(r'<script>([\s\S]*?)</script>', s).group(1))
PY
node --check /tmp/dashboard-script.js
NODE_PATH=/path/to/dependencies/node_modules node tests/weekly.cjs
cmp static/index.html docs/index.html
```

テスト対象：seed件数、保存・再読み込み、週移動と予定なし表示、MTG詳細の開閉、PJ詳細の開閉、Markdownコピー、コピー不可時の代替表示、不正保存データの保護、配布2ファイルの一致、外部スクリプト・CSSの不使用。

この環境には描画ブラウザがないため、390pxでの実描画と視覚的なレイアウトの最終確認は未実施です。
