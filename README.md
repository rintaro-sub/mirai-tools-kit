# Mirai Tools — 学生チーム運営

HTML / CSS / JavaScriptのみの業務ツールです。ミント・太枠・丸ゴシックを継承し、外部通信・実行時依存はありません。

## 起動

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

`http://localhost:8000/static/index.html` を開きます。GitHub Pages用の `docs/` も同一成果物です。相対パスで動作します。

## 毎日の操作

1. ヘッダーの「自分の名前」を設定。ダッシュボードで自分のタスク、今後7日の会議、承認フロー、部門別KPIを確認します。
2. **Ctrl+K / Cmd+K / /** で全データを検索。結果を選ぶと対象の画面・ページへ直接移動します。入力中の `/` は文字入力です。Escapeでダイアログを閉じられます。
3. ヘッダー「通知」で期限超過・3日以内のタスク、承認待ち、未タスク化の相談中議題を確認します。
4. 各部門の「共通タスク」は同じ一覧です。追加・完了はダッシュボードと役員会にも反映します。担当者・状態・期限・カテゴリで絞り込み、期限・名前・優先度でソート、8件ごとにページ送りできます。
5. 議題や面談の「タスク化」は担当・期限を引き継いで即時作成します。担当・期限の変更は共通タスクの「編集」から。既にタスク化した議題は対象タスクへ移動します。
6. 議事録には日時・出席者・議題・決定事項（1行1件）を入力。未タスク化の決定事項が警告され、その場でタスク化できます。

## 部門の作業

| 部門 | 操作 |
| --- | --- |
| 政策立案 | カテゴリ・締切・相談中/決定/却下を設定。賛否は自分の名前ごとに切替、コメントとタスク化 |
| 企画 | 立案/進行/レビュー/完了のテーブル・カンバン切替。編集で担当・期限・優先度・タグ・状態を更新。絞り込んだ全件をCSV出力 |
| 広報 | 原稿保存→レビュー→承認または差し戻し→公開予定。差し戻し後は下書きへ。原稿・SNS変更時は下書きに戻ります。公開日は週カレンダーに表示。X 140字 / Instagram 2200字のカウンタと保存時チェック |
| エンジニア | 課題の担当・優先度・ラベル（タグ）管理。完了/再開、クローズ済み一覧、完了課題からリリースノート生成・編集・ダウンロード |
| 事務局 | 文書カテゴリ・検索・ピン留め（先頭表示）。通知文/議事録/企画書にチーム名・件名・日付を差し込み、編集して保存。FAQも編集可能 |
| 役員会 | 面談メモからタスク化。議題タブには全部門の議題を集約。「相談中」で次回候補を絞り込み |

CSVは現在の検索条件に一致する全件を出力します。カンバンは条件に一致する全件を4列表示します。スマートフォンではテーブルをカード表示、カンバンを縦並びにします。

## 保存とチーム共有

- 全業務データと利用者設定は `mirai.store.js` を通じ、`mirai.portal.store` の **version: 2** に保存。初回は各部門15件以上の架空業務データと共通タスクを生成します。
- 旧 `mirai.portal.*` の企画・部門タスク・議事録・議題・課題・広報原稿/承認状態・通知文を初回に移行。旧キーは削除せず、未分類キーも `legacyArchive` に保持します。
- **JSON出力**で全データをバックアップし、チームメンバーへファイルを渡します。**JSON取込**は確認後に全件置換します。マージ・リアルタイム同期はありません。編集担当を決め、最新版に日付を付けて受け渡してください。取込前のバックアップを推奨します。
- 同じブラウザ・オリジンのstatic/docsと別タブで共用します。自分の名前も共有設定なので取込後に確認してください。ブラウザのデータ削除で消えます。
- JSON取込はバージョン・必須配列・ID・部門・議題/議事録構造を検証します。保存拒否・容量不足時はエラー表示し、保存成功までメモリ上の業務データも変更しません。不正な既存データは上書きしません。
- 削除とJSON置換には確認ダイアログがあります。ローカルの承認管理であり、SNS投稿・通知送信は行いません。認証やアクセス権管理はありません。

## 検証

配布ファイルには追加依存がありません。DOM回帰テストは既存のjsdomを開発環境から指定して実行できます。

```sh
node --check static/app.js
node --check static/mirai.store.js
NODE_PATH=/path/to/test/dependencies node tests/verify.cjs
diff -qr static docs
```

テスト対象: 全7画面・業務タブ、検索と深いリンク、議題/議事録→共通タスク、下書き→レビュー→承認、JSON出力/検証付き取込、旧データ移行、カンバン、テンプレート、削除確認、保存失敗時のロールバック。

DOMテストは描画エンジンを持たないため、390pxでの実描画・キーボードフォーカス・横スクロールの最終目視確認はブラウザで行ってください。
