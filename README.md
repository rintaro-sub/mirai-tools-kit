# Mirai Tools Kit

学生チーム【運営】向けの共通デザイン・キット。
ベースは `rintaro-s/interview` のビジュアル（ミント/角丸/太枠/丸ゴシック）を踏襲。

## 方針
- `static/app.css` に interview のデザインを継承
- 各ツールは同じCSSを使い、ページ名・カード・タブ・チャット風UIを個別に実装
- まずは静的版でUIを揃える。API連携は別途
